# kamakura-food
!Bienvenidos a kamakura food! esta es una aplicacion wedpara getionar pedido de rstaurante de comida japonesa 

## Briefing del proyecto 
 1. objeivo general 
 Desarrolar una interfaz web atractiva, rapida y funcional para un restaurante de comida asiatica/japonesa, que permite a los usuarios visualiza la carta,gestionar pedidos de forma dinamica y comprender laidentidad de marca 

 ### Publico objetivo 
 Amantes de la gastronomia japones usuarios dijitales que buscan experimentar a pedidos a domicilio rapida 


#### tecnologias utilizadas 
-HTML5**: Estructura semantica deñ sitio.
-CSS**: Estilos personalisados 
-JavaScript (E6+)**: Logica de la aplicacion 
-Vites**: Entorno de desarrollo rapido

##### Etructura 
kamakura-food/
│
├── 📂 assets/                  # Recursos estáticos globales
│   ├── 📂 data/                # Archivos de datos (ej. JSON con el menú o productos)
│   └── 📂 img/                 # Imágenes, logos e iconos de la aplicación
│
├── 📂 node_modules/            # Dependencias y librerías instaladas por npm
│
├── 📂 src/                     # Código fuente principal de la aplicación (Lógica JS)
│   ├── cart.js                 # Lógica del carrito (añadir, eliminar, renderizar)
│   ├── events.js               # Manejadores de eventos del DOM (clicks, submits, etc.)
│   ├── menu.js                 # Lógica para mostrar y filtrar los platos/menú
│   ├── receipt.js              # Gestión del recibo, facturación o resumen de compra
│   └── searcher.js             # Lógica del buscador de comida
│
├── 📂 styles/                  # Hojas de estilo CSS
│   ├── cart.css                # Estilos exclusivos de la sección del carrito
│   └── menu.css                # Estilos de la carta o menú de comida
│
├── 📂 tests/                   # Pruebas automatizadas
│   ├── app.test.js             # Test que verifica el DOM (ej. los links del navbar)
│   └── setup.js                # Configuración inicial para el entorno de pruebas
│
├── 📄 .gitignore               # Archivos y carpetas que Git debe ignorar (como node_modules)
├── 📄 index.html               # El punto de entrada HTML de tu aplicación
├── 📄 Instructions.md          # Documento con instrucciones del proyecto/ejercicio
├── 📄 package-lock.json        # Historial exacto de versiones de las dependencias
├── 📄 package.json             # Configuración del proyecto, scripts (como `npm test`) y dependencias
├── 📄 README.md                # Descripción general del proyecto para otros desarrolladores
└── 📄 vite.config.js           # Archivo de configuración para el entorno de desarrollo Vite
